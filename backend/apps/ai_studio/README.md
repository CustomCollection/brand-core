# AI Studio App — CustomCollection Design Engine

## Responsibility
The `ai_studio` app manages AI-powered conversational design generation. It decouples LLM reasoning from image diffusion generation through swappable provider adapters. Users can describe ideas in chat, supply a single reference image, refine past generations, and transfer generated designs directly onto any garment in the manual editor.

## Key Planned Models (Phase 4)
1. `AIConversation`: User chat session instance with title, summary context, and total generations count.
2. `AIMessage`: Messages in the conversation (role: `user`, `assistant`, `system`), text content, and generation instructions.
3. `GeneratedArtwork`: Artwork generated by the image diffusion model, storing S3 key, seed, prompt, parent generation ID, and resolution.
4. `ReferenceImage`: User-uploaded reference image (max 1 active per generation cycle) with S3 key.
5. `UserTokenAccount`: User token ledger with 5 daily free tokens (resets at midnight IST), purchased balance, and lifetime usage.
6. `TokenPackage`: Admin-configurable purchasable token packs (e.g., 1 token for ₹20, 5 tokens for ₹70).
7. `GenerationJob`: Background generation task tracking status (`pending`, `processing`, `completed`, `failed`), retry count, and error payload.

## Swappable Adapter Pattern
- `TextModelAdapter` (Interface): Handles user intent, conversational context, reference image description, and formatted diffusion prompt preparation.
- `ImageModelAdapter` (Interface): Dispatches generation requests (txt2img or img2img with reference/previous generation) and persists output directly to Amazon S3.

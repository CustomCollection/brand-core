# Shared Design Components (`src/components/design/common/`)

## Purpose
Reusable widgets shared between the category catalog browser, manual design editor, and order customization flows.

## Planned Components
- `CategoryGrid.js`: Showcase of customizable garment styles (Oversized Tee, Regular Tee, Hoodie) with pricing and placement badges.
- `ColorVariantSelector.js`: Interactive color swatch picker honoring category-specific color availability rules.
- `SizeVariantSelector.js`: Size selector honoring category-specific size availability rules.
- `PrintMethodBadge.js`: Visual indicator for available printing methods (DTG / DTF) with print dimension tooltips.
- `DesignSessionCard.js`: Card displaying saved user design drafts with thumbnail preview, last modified date, and resume button.
